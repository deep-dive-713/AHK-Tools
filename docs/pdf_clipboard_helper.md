# PDF改行コード処理機能 📄✨

## 概要

PDFからコピーしたテキストの改行コードを自動で処理して、きれいに貼り付けられるようにする機能です。

## 機能一覧

### PDF改行コード処理 (F13 + V)

- 改行コードを統一（CRLF → LF、CR → LF）
- 改行を空白に変換
- 連続する空白を1つに統一
- 行頭・行末の空白を削除
- 句読点の前後の空白を削除

## 使い方

### ステップ1: PDFからテキストをコピー

1. PDFファイルを開く
2. コピーしたいテキストを選択
3. Ctrl + C でコピー

### ステップ2: 改行コードを処理して貼り付け

1. **F13 + V** を押す（自動で処理して貼り付け）
2. 処理と貼り付けが同時に完了！

## 処理例

### 処理前（PDFからコピーした状態）

```text
これはPDFからコピーしたテキストです。

改行コードがめちゃくちゃになっています。

    行頭に余分な空白があります。

句読点の前後に空白があります 。
```

### 処理後（F13 + V）

```text
これはPDFからコピーしたテキストです。改行コードがめちゃくちゃになっています。行頭に余分な空白があります。句読点の前後に空白があります。
```

## 注意事項

- クリップボードの内容が変更されるため、元の内容が必要な場合は事前にバックアップを取得してください
- 処理と貼り付けが自動で実行されます
- メッセージは表示されないため、スムーズに作業できます

## トラブルシューティング

### 機能が動作しない場合

1. AutoHotkey v2がインストールされているか確認してください
2. メインスクリプト（main.ahk）が実行されているか確認してください
3. F13キーが正常に動作するか確認してください

### 処理結果が期待と違う場合

1. 元のテキストの形式によっては手動で調整が必要な場合があります
2. 必要に応じて処理内容をカスタマイズしてください

## カスタマイズ

`src/shortcuts/editing.ahk` ファイルを編集することで、処理内容をカスタマイズできます。

例：

- 特定の文字列を置換
- 改行の処理方法を変更
- 空白の処理方法を変更
